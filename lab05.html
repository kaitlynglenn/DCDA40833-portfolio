Vibe Coding

Lab Requirements

This lab focused on “vibe coding,” or using AI as a coding collaborator by describing what you want in natural language and allowing the AI to generate code. The goal was to experiment with AI-assisted development while still understanding how the code works by reviewing explanations, testing the results, and debugging issues. Through this process, the lab explored both the benefits and limitations of using AI to help build and fix features in a project.

Reflection & Analysis

Vibe Coding Guidelines

For this lab, I wanted to focus on implementing code to enhance my portfolio and to fix code that doesn't work, but I wanted to be sure to understand each step of the code and what it does. I made sure to have AI explain each step to me as it went along so that I wasn't just pasting random code that I had no clue about.

Experiment A: Portfolio Enhancement - Image Carousel

AI Prompt

Create a code for visual studio code to create an image carousel on my index page and explain each step.

Errors

When pressing the next or back buttons on my carousel, nothing would change. I needed to go back to AI and tell me how fix this problem. I was given a new code to implement, and after doing so, the carousel worked perfectly. I was able to click the next and back buttons and see the different images that I had selected for my carousel.

The photos did not fit in the size of the carousel it gave me. I then asked AI to tell me how to fix this issue for my Experiment C.

Experiment C: Debug with AI - CSS Issues

AI Prompt 1

My Carousel images are not fitting the size of the carousel. How can I fix this issue?

AI Prompt 2

Slide 2 of my carousel is not showing up when I open my page on GitHub, only when previewing on VSC. How do I fix this issue?

Errors

When I implemented the code that AI gave me, the images would fit in the slides when I would look on my VSC, but when going to the pages on GitHub, the images were still not fitting the size of the carousel. I then went back to AI and asked it to help me fix this issue again. I was given a new code to implement, and after doing so, the images fit perfectly in the carousel on GitHub.

After inputing my second prompt, it informed me that Github might not be picking up on my new index changes. I was told to put in a test code to see if it is the photos issue or the carousel. After doing the test code, it showed that it was the photos issue, so I had to download the same photo in a different file type in order for it to work.

Lab Reflection

This lab helped me understand how AI can be used as a coding collaborator rather than just a tool for copying code. By asking AI to explain each step and helping me debug problems, I was able to better understand how the HTML, CSS, and JavaScript worked together to create features like the image carousel. This lab demonstrates my ability to use AI responsibly, troubleshoot coding issues, and improve my portfolio while still maintaining my understanding of the code I am implementing.
